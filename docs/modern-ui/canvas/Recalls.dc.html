The Recall button sits on the radar's rim. Hover shows what it holds; a click opens the list. Each place sends the same request as typing its @ command (shown on the right, so players learn them). Places you cannot use are greyed with the reason. Your recall spells follow, greyed outside Magic mode like spells on a bar. Drag any row onto a shortcut bar to make it a slot. A recall the server refuses says why under the target. Your own: any command a server adds (Driftnet on Dreamweave is /dn), saved for that server or for all; right-click one to edit, move or remove it.
